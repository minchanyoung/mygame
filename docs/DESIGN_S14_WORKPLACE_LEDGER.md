# S14 설계안 — 출근 화면 정리 + 자원 증감 장부 + 평가표 평판 출처

> 2026-11-19 · S13 뒤 개선안 중 추천 순서 1번(화면 ⑤ 출근 화면 다이어트 · ⑥ 게이지 증감 내역 · 구조 ① 평판 출처)을 한 단계로 묶는다.

## 0. 문제

- **출근 화면이 길다.** '회사' 탭에 사원증 · 경고 · 게이지 4칸(2×2) · 돈 3칸 · 커리어 · 지난 이야기 · 달력 · 출근 버튼이 세로로 쌓여, 360px 휴대폰에서는 출근 버튼이 화면 아래로 밀린다. 매달 누르는 버튼이 가장 멀다.
- **자원이 왜 줄었는지 남지 않는다.** 사건마다 자원 변화(`EventResult.resourceDelta`)는 기록되지만 이번 달(`currentMonth`)에만 있고 다음 달이면 사라진다. 결과 대화를 넘기면 원인을 다시 볼 곳이 없다.
- **안전한 선택의 평판 비용이 안 보인다.** S13 시뮬레이션: '몸 사리는' 선택(회식 조퇴 −3, 위로 보고 −3, 독감 휴식 −3 …)만 고르면 평판이 평균 42까지 내려앉아 차장 정년. 의도한 현실감이지만, 플레이어는 연말 평가에서 '평판 C'만 보고 이유를 모른다. 현실 난이도에서 무작위 봇이 신중 봇보다 덜 실패하는 문제(S13 §8)의 원인과 같다.

## 1. 목표

1. 360px 화면에서 스크롤 없이 사원증 · 게이지 · 출근 버튼이 보인다.
2. 게이지를 누르면 최근 증감 내역(어떤 사건·선택으로 얼마)이 보인다.
3. 연말 인사평가표에 '올해 평판이 움직인 곳'이 나온다.
4. 정확한 확률은 여전히 숨긴다 (이미 일어난 일의 숫자만 보여 준다 — 결과 화면에서 이미 공개하는 정보와 같은 수준).

## 2. 자원 증감 장부 (엔진)

새 상태 필드 `resourceLedger` — 달이 끝날 때(`nextMonth`) 이번 달 기록을 장부로 옮긴다.

```ts
{ turnIndex, source: 'EVENT' | 'REVIEW' | 'PROMOTION_MISS' | 'MONTHLY',
  eventId?, choiceId?, delta: { health?, mental?, focus?, reputation? } }
```

- **EVENT**: 이번 달 사건 결과마다 1줄 (`EventResult.resourceDelta` 그대로).
- **REVIEW**: 12월 평가의 평판 가감 (S +5 … D −2).
- **PROMOTION_MISS**: 1월 승진 누락 페널티 (정신력 −8 · 평판 −5).
- **MONTHLY**: 나머지 = 달 시작~끝 전체 변화 − 위 항목들. 자연 회복, 나이 듦, 직급 부담, 생활 사건 외 변화가 여기 모인다. 화면에는 '매달 자연 변화'로 표시.
- 보관: 최근 **12개월**만 (세이브 크기 제한, 평가표가 1년 치를 쓴다). 옛 세이브는 빈 장부로 시작(마이그레이션).
- 엔딩·연대기에는 쓰지 않는다 (필요하면 나중에).

## 3. 화면

### 3-1. 출근 화면 ('회사' 탭)
- **출근 버튼 하단 고정**: 탭 바 바로 위에 붙는다(`position: sticky`). 스크롤과 무관하게 항상 보임.
- **게이지 한 줄 압축**: 2×2 큰 게이지 → 4칸 가로 한 줄(아이콘 + 숫자 + 얇은 막대, 지난달 대비 ▲▼ 작은 표시). 위험(20 이하) 표시는 그대로.
- **돈 한 줄**: 현금 · 빚 · 순자산 3칸 타일 → 한 줄 요약 `현금 1,240만 · 빚 0 · 순자산 1,240만`.
- **커리어 · 달력 · 지난 이야기**: 그대로 두되 출근 버튼 아래가 아니라 위 순서 유지, 커리어 카드는 막대만 남기고 설명 문장은 '나' 탭으로.
- '나' 탭은 지금의 큰 게이지·돈 타일을 그대로 둔다 (자세히 보는 곳).

### 3-2. 게이지 증감 내역
- 게이지(회사 탭 한 줄, 나 탭 큰 게이지)를 누르면 아래에서 시트가 올라온다.
- 내용: 그 자원의 **최근 3개월** 증감 목록 — `28세 3월 · 회식 자리 갈등 → 일찍 빠진다  −3`, `매달 자연 변화  +6`. 같은 달 자연 변화는 한 줄로 합친다.
- 맨 위 요약: `최근 3개월 −7 (사건 −13 · 자연 변화 +6)`.

### 3-3. 인사평가표 '올해 평판이 움직인 곳'
- 12월 평가표(결산 화면) 평판 항목 아래에 2~4줄: **깎인 곳 TOP 3**(같은 선택은 묶어서 `×3, −9`) + **오른 곳 TOP 1**.
- 장부 1~11월(그 해) 기준. 평가 자체(점수 계산)는 바꾸지 않는다 — 보여 주기만.

## 4. 결정할 것

- **Q1 출근 화면 압축 정도** — 추천: 위 3-1 전부(게이지 한 줄 + 돈 한 줄 + 버튼 고정). 대안: 버튼 고정만.
- **Q2 증감 내역 범위** — 추천: 최근 3개월. 대안: 올해 전체 / 지난달만.
- **Q3 평판 출처 표시** — 추천: 깎인 곳 TOP 3 + 오른 곳 TOP 1. 대안: 깎인 곳만 / 평판 외 항목(상사 평가 등)도.

## 5. 검증

- 엔진 테스트: 장부 기록(사건·평가·누락·자연 변화 합 = 달 전체 변화), 12개월 보관, 마이그레이션, 평가표 출처 TOP 계산.
- 시뮬레이션: 규칙 변화 없음 → 실패율 그대로여야 한다 (회귀 확인용으로 300판).
- 화면: 360px에서 출근 버튼이 첫 화면에 보이는지, 시트 열고 닫기, 다크 모드.

## 7. 구현 결과 (2026-11-19)

### 엔진
- `ledger.ts`: `monthLedgerEntries`(그달 기록 → 승진 누락 · 평가 · 사건 · 나머지 순), `closeMonthLedger`(`nextMonth`에서 호출, 최근 12개월만), `reputationSources`(평가표 TOP 계산).
- 상태 `resourceLedger`, 평가 상세 `reputationSources`(사건·선택 ID만 저장, 라벨은 공개 뷰에서). 마이그레이션: 옛 세이브 빈 장부, 옛 평가표 빈 출처.
- 공개 뷰 `resourceTrail { entries, lastMonth }`: 최근 3개월, 최신 달이 위·같은 달 안은 일어난 순서. 사건은 `사건 제목 → 고른 선택`, 나머지는 '매달 자연 변화' · '연말 인사평가' · '승진 누락'.
- 승진 누락·평가의 평판 변화는 규칙값으로 적고, 0·100에서 잘린 차이는 '자연 변화'에 섞인다 (드문 경우라 그대로 둠).
- 설계에 없던 것: 평판에도 자연 회복 +1/월이 있어(`naturalChange.reputation`) 평판 시트에 '매달 자연 변화 +1'이 매달 보인다. 정보로서 맞으므로 그대로.

### 화면
- 출근 화면('회사' 탭): 사원증 → 경고 → **게이지 한 줄**(아이콘·숫자·막대·지난달 ▲▼) → **돈 한 줄** → 커리어(설명 문장 숨김) → 지난 이야기 → 달력. **출근 버튼은 탭 바 위 `bottom-dock`에 고정**.
- 게이지(회사 탭 한 줄 · 나 탭 큰 게이지)를 누르면 **아래에서 올라오는 시트**: 요약(최근 3개월 합 = 사건·평가 + 자연 변화) + 줄 목록. Esc·바깥 누르기·닫기로 닫힘.
- 12월 인사평가표 '사내 평판' 항목 아래 **'올해 평판이 움직인 곳'** 상자 (같은 선택은 `×3 −9`).
