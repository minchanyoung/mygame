# S12 설계안 — 직무별 연재 (C1)

> 상태: **승인 (2026-11-18)** — Q1 직무당 1편, Q2 한 번에 1편, Q3 입사 2~4년 차에 반드시, Q4 중간 보상.
> 근거: `PROGRESS.md` 로드맵 Phase 5, S8 연재 구조(`DESIGN_S8_STORY_ARCS.md`), 직무 전용 단발 사건 20개(직무당 4).

## 0. 문제와 목표

| 문제 | 지금 | 목표 |
|---|---|---|
| 직무를 골라도 이야기가 비슷하다 | 직무 전용 사건은 단발 4개뿐. 연재 4편은 모든 직무 공통 | 개발자는 개발자의, 영업은 영업의 **긴 이야기** |
| 다시 할 이유 | 직무를 바꿔도 체감 차이가 작다 | "이번엔 영업으로 해 볼까" — 직무마다 다른 연재와 결말 |

## 1. 연재 5편 (직무당 1편 × 4화, 추천)

S8과 같은 구조: 1화는 확률로 뜨는 업무 사건, 2화부터 예약 전용(2~3개월 간격), 참여 동료를 이어받고 앞 화의 선택이 플래그로 남아 갈린다. 동료가 떠나면 정리 화로 끝난다.

| 직무 | 연재 | 줄거리 (1 → 2 → 3 → 4화) | 결말 갈림 |
|---|---|---|---|
| 개발 | **차세대 시스템** | 무리한 일정의 전면 개편 착수 → 기술 부채 폭탄 → 오픈 D-day 장애 → 회고 | 성공 오픈의 주역 / 연기를 주장해 살아남음 / 사고 책임 공방 |
| 인사 | **구조조정 명단** | 비밀 TF 차출 → 명단에 친한 동료 이름 → 소문 유출 → 발표 날 | 원칙대로 / 동료를 지킴(대가) / 명단을 흘림(낙인) |
| 영업 | **연간 최대 계약** | 대형 고객 입찰 → 경쟁사 덤핑 → 접대·리베이트 유혹 → 계약 결과 | 정공법 수주 / 실패했지만 신뢰 / 리베이트로 수주(1년 뒤 감사) |
| 재무 | **상장 준비** | IPO 실사 차출 → 숫자 맞추기 압박 → 감사인과의 줄다리기 → 상장 당일 | 우리사주 목돈 / 원칙 지켜 상장 연기 / 분식 가담(낙인) |
| 기획 | **대표님의 신사업** | 대표 직속 TF → 시장조사 vs 대표 고집 → 파일럿 실패 → 보고 자리 | 피벗 성공 / 정직한 보고로 신뢰 / 책임 떠안기 |

- 각 편: 4화 + (동료 기반이면) 정리 화 1 → 약 24~25개 사건, 결말 선택은 편당 3개 → 도감 '연재 결말' +15칸 안팎.
- 결말 화는 실직으로 이어지지 않는다 (S8 규칙 유지). 낙인·감사 예약 같은 대가는 있다.
- 결말 보상: 승진 포인트·평판·특성·현금(재무 우리사주) — 크기는 Q4.

## 2. 등장 규칙

- 1화 조건: 그 직무, 재직 1년 이상, 진행 중 연재 없음(Q2), 한 판에 한 번.
- 1화 가중치는 입사 1~6년 차에 한 번은 만날 정도로 (Q3).
- 이직해도 직무는 그대로라 연재는 이어진다. 연재 중 이직하면 정리 화.

## 3. 도감·업적

- 연재 결말은 도감에 자동으로 들어간다 (S10 구조). 도감 칸 수가 늘어난다.
- 업적 '이야기꾼'(모든 연재 완결)은 **공통 연재 4편 기준으로 유지**한다. 직무 연재는 한 판에 하나만 볼 수 있어서, 넣으면 다섯 직무를 다 해야 한다.
- 새 업적 **'다섯 개의 명함'**: 직무 연재 5편을 모두 한 번 이상 완결.

## 4. 엔진·화면

- 엔진 변경은 거의 없다 (S8 연재 엔진 재사용). 필요하면 조건에 `seriesNone`을 연재 종류별로 나눈다(Q2).
- 사건 화면은 기존 `연재 · 차세대 시스템 2/4화` 표시, 결산 달력 '?' 그대로.
- 시뮬레이션: 직무별 연재 시작률·완결률, 결말 분포, 실패율 변화 확인.

## 5. 밸런스

- 직무 연재 결말이 커리어를 크게 흔들면 직무 간 유불리가 생긴다. 시뮬레이션에서 직무별 실패율·부장 도달률 차이가 ±5%p 안인지 본다.

## 6. 결정할 것

- **Q1 분량**: 직무당 1편(5편) / 직무당 2편(10편)
- **Q2 동시 진행**: 연재는 한 번에 1편(지금 규칙) / 직무 연재는 공통 연재와 따로 동시에 가능
- **Q3 등장**: 확률(평균 1~6년 차) / 입사 2~4년 차에 반드시 시작
- **Q4 결말 보상**: 크게(승진 포인트 2~3·연봉·우리사주 목돈·특성) / 작게(평판·관계·특성 위주)

## 7. 구현 결과 (2026-11-18)

### 들어간 것
- 직무 연재 5편 × 4화 + 정리 화 3(개발·인사·재무, 함께하던 동료·팀장이 떠나면) + 공통 후속 '감사실에서 온 메일' 1 = **사건 24개** (총 126개).
  - 개발 「차세대 시스템」(동료 개발자), 인사 「구조조정 명단」(친한 동료), 영업 「연간 최대 계약」(고객사 상무), 재무 「상장 준비」(팀장), 기획 「대표님의 신사업」(대표).
  - 결말은 편당 4개, 앞 화의 선택(플래그)으로 갈린다. 모든 경로를 전수 확인해 막다른 길 0, 결말 20개 모두 도달 가능.
  - 나쁜 길(영업 리베이트, 재무 분식 상장)은 1년 뒤 감사실 사건을 예약한다 (실직 없음, 평판·승진 포인트 대가).
- 엔진: 사건 필드 `guaranteeFromTurn` — 입사 2년 차부터 확률로, **36개월(4년 차)부터는 조건이 맞으면 추첨 없이** 업무 칸에 연다. 다른 연재가 진행 중이면 끝난 뒤로 밀린다(한 번에 1편).
- 연재에 `job` 표시: 업적 '이야기꾼'은 공통 연재 4편만, 새 업적 **'다섯 개의 명함'**(직무 연재 5편 완결). 업적 17개.
- 도감 '연재 결말'에 💼 직무 연재 칸(꼬리표에 직무, 못 본 칸 힌트 '○○ 직무에서만 볼 수 있는 결말'). 도감 **108칸**.
- 콘텐츠 검증: 보장 사건은 예약 전용 불가, 직무 연재 1화는 그 직무 조건 필수.
- 시뮬레이션 리포트: 직무별 연재 시작(4년 차까지)·완결·시작 연차, 직무별 실패율·부장 도달.
- 테스트 6개 (`job-series.test.ts`), 전체 232개.

### 시뮬레이션
- 직무 연재: 모든 직무에서 4년 차까지 **100%** 시작, 완결 97~100%, 시작 중앙값 3년 차.
- 난이도 요약 (500판, 보상 미세 조정 전): 행동 안 씀 쉬움 6.0% · 보통 24.6% · 현실 55.8%(목표 상한 55%를 0.8%p 넘음), 행동 활용 신중 봇 보통 7.8%, 진행 불능 0건.
  - 최종 500판 재측정은 메모리 부족으로 시스템이 중단했다. 그 뒤 바꾼 것은 개발 결말 승진 포인트 2→1, 재무 우리사주 월급 4→3개월, 재무·개발 상사 관계 증가 제거뿐이다.
- 연재가 직무에 주는 효과 (신중 봇 1000판, 연재 있음 − 없음):

| | 개발 | 인사 | 영업 | 재무 | 기획 |
|---|---|---|---|---|---|
| 50세 전 실패 | +1%p | +1%p | −4%p | −3%p | −4%p |
| 정상 엔딩 중 부장 | +7%p | −3%p | +5%p | +10%p | −1%p |

  - 실패율은 모든 직무 ±5%p 안. 부장 도달은 재무 +10%p·개발 +7%p로 목표(±5%p)를 넘지만, 직무당 표본 170~240판이라 오차(±5%p)의 두 배 안쪽이다. 관계·보상을 줄여도 수치가 거의 그대로여서 더 깎지 않았다. 사람 플레이 뒤 다시 본다.
- **직무 간 격차는 S12 이전부터 있었다** (연재 없이 신중 봇 실패: 개발 2% · 인사 6% · 영업 23% · 재무 4% · 기획 14%, 부장: 영업 20% vs 재무 51%). 영업·기획 단발 사건이 더 가혹하다. 이번 범위 밖 — 다음 후보로 남긴다.
