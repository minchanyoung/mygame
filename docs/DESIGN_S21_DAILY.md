# S21 설계안 — 오늘의 출근 (B4 오늘의 시드)

> 상태: **구현 (2026-11-20)**. 검수 없이 진행 — 결정은 추천안으로 정하고 이 문서에 남긴다.
> 근거: `PROGRESS.md` 남은 후보 B4 "오늘의 시드: 모두가 같은 조건으로 하루 한 판, 결과 비교"

## 결정

- **같은 조건**: 시드를 `daily-YYYY-MM-DD`(한국 시간, 서버 시계)로 고정. 카드 3장·인생 목표 후보·동료·사건 추첨 흐름이 모두 시드에서만 나오므로
  같은 날이면 누구나 같은 출발점이다(이름·성별은 카드에 영향 없음). 난이도는 **보통 고정**.
- **시작**: 프로필 화면의 '📅 오늘의 출근으로 하기' 체크(난이도 선택은 잠김). API `POST /api/runs`에 `daily: true`.
- **점수** (엔딩 확정 뒤, 항목별 공개):
  버틴 햇수 ×10 · 최고 직급 ×80(사원 0 ~ 부장 320) · 순자산 1천만 원당 1점(상한 300, 음수 0) · 정상 엔딩 +200 · 별을 달다 +200 · 인생 목표 달성 +100.
  - 오래 버티는 것, 높이 올라가는 것, 모으는 것이 비슷한 무게가 되게 했다(정년 완주 360 · 부장 320 · 10억 300).
- **순위**: 엔딩이 확정될 때 서버가 기록. **플레이어당 하루 첫 판만** 순위에 오른다(다시 해 보는 건 자유). 플레이테스트로 조작된 판은 제외.
  `GET /api/daily?date=` → 오늘 상위 10명 + 내 순위(플레이어 토큰). 플레이어 ID는 응답에 넣지 않는다.
- **화면**: 엔딩 화면 '📅 오늘의 출근' 카드(점수 내역 칩 + 순위표, 내 줄 강조). 공유 이미지에 날짜·점수 한 줄.
- 저장소: `DailyStore`(메모리 / 로컬 파일 `.data/daily/날짜.json`). 나중에 DB로 교체.

## 함께 고친 것
- 공유 이미지: 긴 엔딩 제목이 도장과 겹치던 문제 — 글자 크기를 88 → 76 → 64로 줄여 보고, 그래도 길면 띄어쓰기에서 두 줄.
