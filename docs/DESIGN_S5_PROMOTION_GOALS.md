# S5 설계안 — 승진 심사(A1) + 인생 목표(C1)

> 상태: **승인 (2026-11-17)** — 결정은 §4. 승인 후 ② 엔진·콘텐츠·테스트 → ③ 화면 순으로 구현한다.
> 근거: DEVELOPMENT_PLAN §5.4(승진은 자동이 아니라 성과·포인트·상사 평가·정치력의 합), §20.1(12월 평가·1월 연봉), §21.2(상사 교체), §26(실직 규칙).

## 0. 목표

- **승진**: 50세까지 버티는 동안 "올라가고 있다"는 감각. 직급이 오르면 연봉·사건·상사가 실제로 달라진다.
- **인생 목표**: 시작할 때 고르는 장기 목표. 매달 진행도가 보이고, 엔딩에서 달성 여부가 평가된다.
- 둘 다 기존 구조(12월 평가 → 1월 연봉 조정, 사건 조건 `ranks`, `reassignBossIfNeeded`)를 재사용한다.

## 1. 승진 심사 (A1)

### 1.1 직급 사다리

| 직급 | 최소 근속(현 직급) | 필요 승진 포인트 | 승진 시 연봉 인상 |
|---|---|---|---|
| 사원 → 대리 | 2년 | 5 | +10% |
| 대리 → 과장 | 3년 | 7 | +12% |
| 과장 → 차장 *(신설 제안)* | 4년 | 8 | +12% |
| 차장 → 부장 | 4년 | 10 | +15% |

- 최소 근속만 채워서는 안 된다(자동 승진 금지, §5.4).
- **차장 신설은 결정 필요(Q1).** 넣으면 24~60세 사이 승진이 4번이 된다. 빼면 사다리가 3번에서 끝난다.
- 표의 숫자는 시뮬레이션 뒤 조정한다(§1.6 목표 분포).

### 1.2 승진 포인트(PP)

| 출처 | 포인트 |
|---|---|
| 12월 평가 등급 | S +4 · A +3 · B +2 · C +1 · D 0 |
| 큰 성공 사건 (콘텐츠의 `PROMOTION_POINT_DELTA` 효과) | +1 ~ +2 |
| 사내 낙인·징계성 사건 | −1 ~ −2 |

- 포인트는 승진하면 0으로 초기화되고, 누락되면 유지된다.
- 이직(후속 단계)에서도 유지하지 않는다. 회사 내부 포인트다.

### 1.3 심사 시점과 판정 (1월, 연봉 조정 직전)

1월 결산에서 근속과 포인트가 조건을 넘으면 **승진 심사**가 자동으로 열린다. 판정은 서버 RNG로 하고, 정확한 확률은 비공개다.

```
기본 55%
+ 초과 포인트 1점당 +8%p (최대 +24%p)
+ 회사 승진 정책 보정
    SENIORITY   : 근속 초과 1년당 +5%p
    PERFORMANCE : 직전 평가 S +15%p / A +8%p / C 이하 −10%p
    POLITICS    : 상사 호감 70↑ +12%p / 40↓ −12%p
+ 상사 신뢰 70↑ +5%p
− 사내 낙인 Lv.1 −5%p / Lv.2 −15%p (§6 표 그대로)
− PIP 경고 중이면 심사 자체가 열리지 않음
→ 5~95%로 자름
```

- **성공 → 인사발령**
  1. 직급이 오르고, 연봉 인상(1.1)이 그해 연봉 조정에 더해진다.
  2. 포인트는 0이 된다.
  3. 상사 직급이 내 직급 이하가 되면 `reassignBossIfNeeded`로 새 상사가 배치된다. 기존 상사는 '전 상사'로 기억을 보존한다(§21.2).
- **실패 → 승진 누락**: 정신력 −8.
  - 포인트는 유지되고, 다음 해 심사 확률이 +10%p 오른다(누락 보정).
  - 2년 연속 누락이면 "후배가 먼저 달았다" 사건이 예약된다(정신력·평판 이벤트, 실직 없음).

### 1.4 직급이 바꾸는 것

| | 사원·대리 | 과장·차장 | 부장 |
|---|---|---|---|
| 사건 | 실무·실수·선배 | **팀원 관리**(후배 실수 수습, 면담, 평가 작성), 예산 | **임원 보고**, 조직개편, 구조조정 명단 작성 |
| 상사 | 과장~부장 | 차장~부장 | 임원 |
| 부담 | — | 매달 집중력 자연 회복 −1 | 매달 정신력 자연 회복 −1 |
| 50세 이후 | — | — | 희망퇴직 권유 사건 가중치 ↑ (조기 은퇴 경로) |

- 직급 전용 사건은 기존 조건 `conditions.ranks`로 거른다.
- 신규 사건 목표: 과장급 이상 5개, 부장 3개, 승진 관련 3개(심사 대기, 누락 후속, 후배 추월). 업무 사건은 기존처럼 메신저 대화로 쓴다.

### 1.5 화면

- **메인(상태 패널)**: 직급 배지와 승진 진행 막대. 예: `대리 → 과장 · 근속 2/3년 · 포인트 5/7`. 포인트 숫자는 공개하고, 확률은 숨긴다.
- **1월 결산**: '인사발령' 공문 형식. "위 사람을 과장에 임함" + 직인 도장. 누락이면 회색 '보류' 도장과 위로 메시지.
- 승진 전후의 상사 교체를 메신저 시스템 메시지로 보여준다. 예: "OOO 부장이 새 팀장으로 배치되었습니다".

### 1.6 밸런스 목표 (1,000회 시뮬레이션에 지표 추가)

- 60세까지 살아남은 판 중 최종 직급(신중한 봇 기준): 부장 25~40% · 차장 30~40% · 과장 이하 나머지
- 평균 첫 승진 나이: 27~28세
- 승진이 50세 전 실패율을 지금보다 5%p 넘게 바꾸지 않을 것

## 2. 인생 목표 (C1)

### 2.1 고르는 시점

캐릭터 선택 직후, 첫 구직 전에 고른다. **무작위 3장 중 1장을 고르는 방식을 제안하고, 결정이 필요하다(Q2).** 선택한 목표는 한 판 동안 바꿀 수 없다.

### 2.2 목표 카드 (6종)

| 목표 | 달성 조건 (판정 시점: 엔딩) | 성격 |
|---|---|---|
| 🏠 **내 집 마련** | 순자산(현금 − 빚) 3억 원 이상 | 돈 |
| 👔 **부장 달기** | 최종 직급 부장 | 커리어 |
| 🎖 **정년 완주** | 60세 정년 은퇴 엔딩 | 버티기 |
| 💸 **빚 없는 인생** | 빚 0원 + 현금 1억 원 이상 | 돈·절제 |
| 🌿 **워라밸 수호자** | 엔딩 시 체력·정신력 모두 60 이상 + 50세 이후까지 근무 | 건강 |
| 🏆 **에이스** | 연말 평가 S를 4회 이상 | 성과 |

- 배경 특성과 어울리는 목표가 섞여 나오도록, 3장 중 1장은 추천 직무처럼 배경 기반으로 고른다.
- 수치(3억, 1억, S 4회)는 시뮬레이션 뒤 조정한다. 목표: 신중한 봇 기준 각 목표 달성률 20~45%.

### 2.3 진행 중

- 메인 화면에 목표 카드와 진행 막대를 둔다. 예: `내 집 마련 · 순자산 4,200만 / 3억 (14%)`.
- 25%·50%·75% 도달 때 결산에 짧은 축하 메시지를 띄우고 정신력 +3을 준다. 진행 동기 부여용이며 보상은 작다.
- 목표가 사실상 불가능해지면(예: 부장 목표인데 50세에 대리) 경고 대신 "목표를 다시 생각할 때" 메시지만 띄우고, 바꿀 수는 없다.

### 2.4 엔딩

- 엔딩 화면에 **인생 목표: 달성 / 미달성** 칸이 생긴다. 목표별로 달성·미달성 에필로그 문장을 둔다(6 × 2 = 12문장, 블랙코미디 톤 유지).
- 실패 엔딩(50세 전 실직)이어도 목표 판정은 한다. 예: '부장 달기' 달성 후 48세에 구조조정. **결정 필요(Q3)**
- 별도 점수나 등급은 이번 단계에 넣지 않는다. 연대기 엔딩(D1)에서 다룬다.

## 3.5 구현 후 조정 (시뮬레이션 1,000회 결과 반영)

설계안 수치로 돌리자 정상 엔딩의 95~100%가 부장에 도달하고 순자산 중앙값이 14억까지 올라가 아래처럼 조정했다.

| 항목 | 설계안 | 구현 |
|---|---|---|
| 사다리 (근속/포인트/확률 보정) | 2·3·4·4년 / 5·7·8·10 | 2·4·5·6년 / 4·8·14·22, 단계별 확률 보정 0·−5·−20·−35%p |
| 평가 등급 포인트 | S4 A3 B2 C1 D0 | S3 A2 B1 C0 D0 |
| 직급 부담(매달 회복 −1) | 과장·차장 집중력, 부장 정신력 | **제거** — 무작위 봇 실패율이 62%로 폭증. 직급 부담은 직급 전용 사건으로만 준다 |
| 물가 상승 | 없음 | **신설** 생활비 연 4% 복리 상승 (연봉만 오르고 생활비는 36년 고정이던 문제) |
| 1월 처리 순서 | 승진 → 연봉 조정 | 연봉 조정 → 승진 (결산에 '연봉계약서'와 '인사발령'을 따로 보여주기 위함, 결과 차이 없음) |
| 내 집 마련 | 순자산 3억 | 순자산 10억 |
| 빚 없는 인생 | 현금 1억 | 현금 5억 |
| 워라밸 수호자 | 체력·정신력 60 | 90 |
| 에이스 | S 4회 | S 6회 |

시뮬레이션 결과 (신중 봇 / 무작위 봇):

- 정상 엔딩 중 부장 도달: **43%** / 91%. 무작위 봇은 위험한 판정 선택을 많이 해 S등급이 잦다.
- 첫 승진 중앙값 28세 / 27세, 50세 전 실패 23.7% / 29.2%
- 목표 달성률: 에이스 20% / 48%, 빚 없는 인생 41% / 67%, 부장 달기 31% / 60%, 내 집 마련 30% / 54%, 정년 완주 77% / 37%, 워라밸 70% / 27%
- 정년 완주·워라밸은 "버티기·컨디션" 목표라, 정확한 확률을 알고 늘 안전한 선택만 하는 신중 봇에게는 쉽다. 사람 플레이는 두 봇 사이일 것으로 본다.

추가된 것: 직급·승진 사건 11종(신입 사고 수습, 평가 쓰기, 에이스 사직, 예산 쟁탈전, 임원 보고, 명단 작성, 희망퇴직 소문 → 면담, 승진 시즌, 승진 턱, 후배 추월). 희망퇴직 면담은 50세 이상·사전 소문 플래그가 있어야 열리고, 수락하면 위로금과 함께 조기 은퇴(정상 엔딩)한다. 거절 선택지가 항상 있다.
