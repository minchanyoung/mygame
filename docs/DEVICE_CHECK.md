# 실제 기기 점검 (Phase 2 · E1)

> 2026-11-18 · 자동 점검(휴대폰 크기 브라우저) 완료, 사용자 휴대폰 점검 대기

## 1. 휴대폰으로 접속하기

1. PC와 휴대폰을 **같은 공유기**에 연결한다 (PC 유선 + 휴대폰 와이파이도 됨).
2. PC에서 `npm run playtest:lan` 실행 → 터미널에 나온 주소(예: `http://192.168.0.174:5173`)를 휴대폰 브라우저에 입력.
3. 안 열리면
   - 휴대폰이 공유기 와이파이에 붙어 있는지 (데이터·게스트 와이파이 X)
   - Windows 방화벽에 'Node.js JavaScript Runtime' 인바운드 허용 규칙이 있는지
     (`Get-NetFirewallApplicationFilter -Program "C:\Program Files\nodejs\node.exe" | Get-NetFirewallRule`)
   - API(3001)는 PC 안에서만 열린다. 휴대폰은 웹 서버(5173)를 통해서만 API를 부른다 — 정상.

> 이 모드는 http(비보안)라서 일부 브라우저 기능(`crypto.randomUUID` 등)이 없다. 실제 출시는 https.

## 2. 자동 점검 결과 (360×780 갤럭시, 390×844 아이폰 크기 · 밝게/어둡게)

`playwright-core` + 설치된 Chrome으로 첫 화면 → 스펙 → 목표 → 지원 → 회사·탭 4개 → 사건 → 결과 → 엔딩을 열어
화면 축소·가로 넘침·화면 밖 요소·40px 미만 터치 영역·12px 미만 글자를 검사했고,
**API 없이 탭만으로 처음부터 6개월**을 휴대폰 접속 주소(LAN)로 끝까지 플레이했다.

### 고친 것

| 문제 | 증상 | 원인 → 수정 |
|---|---|---|
| **모든 버튼이 '네트워크 오류'** | 휴대폰(http://192.168…)에서 스펙 선택·출근·선택지 등 서버로 가는 동작이 전부 실패 | 요청 키를 `crypto.randomUUID()`로 만들었는데 https·localhost에서만 존재 → `getRandomValues`로 대체 |
| **스펙 선택 화면이 축소되어 보임** | 360px 기기에서 페이지가 870px로 인식되어 작게 보이고 옆으로 밀림 | 카드 안 화면낭독기용 숨김 글자(`.sr-only`)가 가로 스크롤 줄 밖으로 빠짐 → 스크롤 줄을 위치 기준으로 |
| 단어 중간 줄바꿈 | '확/인이', '성공할수/록', '1.5/억' | 앱 전체 `word-break: keep-all` (긴 낱말만 강제 줄바꿈) |
| 상단 바 양옆 비침 | 스크롤하면 '오늘도 출근' 바 좌우로 아래 내용이 보임 | 바 배경을 화면 끝까지 |
| 달력 '평가' 칸 두 줄 | 12칸이 칸당 21px라 '평가'가 깨짐 | 평가 달은 숫자 12 + 노란 테두리 (머리글에 '12월 연말 평가') |
| 작은 글자 | 하단 탭 11px, 달력 11px, 말풍선 이름·사건 진행 11.5px | 12px로 |
| 스펙 A/B/C 점 | 32px라 누르기 어려움 | 보이는 크기 유지, 누르는 영역 44px |
| 답장 패널이 대화를 덮음 | 선택지가 길면 아래 고정 패널이 화면 대부분을 차지 | 패널 최대 높이 60%, 넘치면 패널 안에서 스크롤 |
| 엔딩 그래프 | 해마다 7px 막대를 정확히 눌러야 함, 축 글자 9px, '0만', 누르면 포커스 테두리 | 그래프 어디든 누르거나 **가로로 끌면** 가장 가까운 해 선택(세로 스크롤은 유지), 축 11px, '0', 키보드 ←→, 탭 시 테두리 없음 |

### 남은 지적 (의도된 것)
- 사원증의 'EMPLOYEE ID' 장식 글자 11px, 그래프 축 글자(화면 폭에 따라 10px 안팎).

## 3. 휴대폰에서 직접 볼 것 (자동 점검으로는 못 보는 부분)

- [ ] **접속**: 휴대폰에서 주소가 열리고, 새 인생 → 스펙 → 목표 → 지원 → 출근 → 선택지까지 오류 없이 되는가
- [ ] **노치·홈 바**: 상단 바가 상태 표시줄(시계)에 가려지지 않는가, 하단 버튼·탭이 홈 바/제스처 영역에 가려지지 않는가 (아이폰 사파리 특히)
- [ ] **주소창**: 스크롤할 때 주소창이 접혔다 펴져도 아래 버튼이 튀거나 가려지지 않는가
- [ ] **키보드**: 이름 입력 시 키보드가 '진행하기' 버튼을 가리지 않는가, 화면이 확대되지 않는가 (iOS는 16px 미만 입력칸에서 자동 확대)
- [ ] **스펙 카드 스와이프**: 옆으로 넘기기가 부드러운가, A/B/C 점을 누르면 그 카드로 가는가
- [ ] **선택지 누르기**: 한 번에 눌리는가, 잘못 눌릴 만큼 붙어 있지 않은가. 치명 경고 선택지는 두 번 눌러야 확정되는가
- [ ] **엔딩 그래프**: 손가락으로 가로로 끌면 해가 바뀌고, 세로로 쓸면 페이지가 스크롤되는가
- [ ] **글꼴**: 제목 글꼴(검은 고딕)이 로딩되는가, 데이터 연결이 느릴 때 글자가 늦게 뜨거나 깜빡이지 않는가
- [ ] **다크 모드**: 휴대폰을 다크 모드로 바꿨을 때 읽기 편한가
- [ ] **뒤로 가기**: 안드로이드 뒤로 가기 버튼을 누르면 어떻게 되는가 (지금은 앱 밖으로 나갈 수 있음 — 기대와 다르면 알려 주기)
- [ ] **이어하기**: 브라우저를 껐다 켜도 '이어하기'로 돌아오는가
- [ ] 기기·브라우저 이름(예: 갤럭시 S23 · 삼성 인터넷)을 함께 적어 주기

엔딩 화면 미리 보기는 `PLAYTEST.md` B6의 방법(콘솔에 세션 넣기)이 휴대폰에서는 어렵다.
필요하면 PC 브라우저에서 미리 보기로 열어 둔 판의 주소 대신, 플레이테스트 도구로 나이를 59세로 올려 엔딩까지 진행한다.
