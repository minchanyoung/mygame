# 플레이테스트 안내 (검수 ③)

## 실행

```bash
npm install          # 처음 한 번
npm run playtest     # API(플레이테스트 도구 ON) + 웹을 함께 실행
```

- 브라우저에서 **http://localhost:5173** 을 연다. 종료는 터미널에서 `Ctrl+C`.
- 휴대폰 화면 확인: 브라우저 개발자도구(F12) → 기기 모드 → 너비 **360px**.
- 같은 와이파이의 휴대폰으로 직접 보려면 웹을 `npm run dev -w @company-life/web -- --host`로 띄우고 표시되는 Network 주소로 접속한다(이 경우 API는 별도 터미널에서 `PLAYTEST_TOOLS=1 npm run dev:api`).
- 저장 위치: `apps/api/.data/runs/` (로컬 파일, 지워도 됨). 이전 버전에서 만든 저장은 불러올 수 없으니 새 게임을 시작한다.

## 🧪 플레이테스트 도구

화면 맨 아래 **"🧪 플레이테스트 도구"**를 펼친다 (`npm run playtest`로 실행했을 때만 보임).

| 기능 | 쓰는 곳 | 용도 |
|---|---|---|
| 현재 사건 정확한 확률 | 사건 화면 | 숨겨진 성공률과 보정 내역 확인 |
| 이번 달 후보 사건 | 월 시작 화면 | 어떤 사건이 몇 % 확률로 나올지 |
| 숨김 정보 | 어디서나 | NPC 호감·신뢰·경쟁, 플래그, 부채 한계 |
| 빠른 조정 / 직접 입력 | 월 시작 화면 | 자원·현금·빚·나이 변경 |
| 승진 조정 (S5) | 월 시작 화면 | "12월로", "승진 심사 대상으로"(1월 + 포인트·근속 충족), "차장으로", "부장으로" |
| 특성 레벨 | 월 시작 화면 | 활성 특성 5종 Lv.0~2 설정 |
| 사건 강제 발생 | 월 시작 화면 | 원하는 사건으로 이번 달 시작 |

- 도구를 한 번이라도 쓴 판은 **"조작된 기록"**으로 영구 표시된다(나중에 랭킹에서 제외).
- 운영 환경(`NODE_ENV=production`)에서는 켜지지 않는다.

## 검수 체크리스트

> 월 시작 정산에서 자연 회복(체력 +2, 정신력 +3, 집중력 +2, 평판 +1)이 먼저 적용된다. 그래서 위험 확인용 프리셋은 1로 낮춰 두었다.

### A. 기본 흐름
- [ ] 이름·성별 입력 → 카드 3장의 이름·성별이 같은가
- [ ] 첫 구직: 세 번째 카드가 "합격 확정 100%"인가, 다른 카드에 떨어지면 그 회사로 입사하는가
- [ ] 월 시작 → 사건 → 결산 → 다음 달이 자연스럽게 이어지는가
- [ ] 결산에 월급·생활비·자원 변화가 이해되는가

### B. 실직 엔딩 (도구 사용)
| 확인 | 방법 | 기대 결과 |
|---|---|---|
| 과로 실직 | 빠른 조정 "체력 1" → "금요일 오후의 전산 장애" 강제 → ⚠ 선택지 | 결산에 예고 → "결말 보기" → 과로 실직 |
| 번아웃 실직 | "정신력 1" → "회의실의 공개 질책" 강제(상사가 나쁜 성향일 때) → "참고 넘어간다" | 번아웃 실직 |
| 대형 사고 실직 | "집중력 1" → "구조조정 소문" 강제 → "성과 자료 정리"(집중력 -3) | 직무별 문구 (개발이면 DELETE) |
| 사내 퇴출 | "평판 1" → "회식 자리의 불화" 강제 → "조용히 먼저 일어난다"(평판 -2) | 사내 퇴출 |
| 빚더미 퇴장 | "부채 한계 직전" → 월 시작(생활비로 부채 증가 가능) | 빚더미 퇴장 |
| 구조조정 | "구조조정 소문" 강제 → 다음 달 "구조조정 명단" 강제 → "면담" 실패 시 | 구조조정 엔딩 |
| 조기 은퇴 | "50세로" + 위 방법 중 하나 | "조기 은퇴 — (원인)" 정상 엔딩 |
| 정년 은퇴 | "59세로" + "전부 100" 후 12월까지 진행 | 정년 은퇴 |

- [ ] 20 이하 자원에 경고 배너와 막대 색이 바뀌는가
- [ ] ⚠ 선택지는 두 번 눌러야 확정되는가
- [ ] 엔딩 문구 톤이 의도와 맞는가 (수정은 `packages/content/data/endings.json`)

### B2. S2 추가 기능
- [ ] 12월 결산에 "📋 연말 인사평가" 등급이 나오고, 다음 1월 결산에 "💰 연봉 조정"이 나오는가 (빠르게 보려면 도구로 월을 넘기거나 11월 전후에서 시작)
- [ ] 월 시작 화면에 "최근 평가 N등급"이 보이는가
- [ ] 직무별 사건이 내 직무에서만 나오는가 (개발: 배포 직후의 장애 제보 / 인사: 하루 종일 면접관 / 영업: 분기를 건 대형 계약 / 재무: 맞지 않는 결산 / 기획: 신사업 제안 발표)
- [ ] 연쇄: 개발 "임시 패치" → 4개월 뒤 "돌아온 임시 패치", 기획 "숫자 부풀리기" 성공 → 3개월 뒤 "다시 꺼내 든 발표 자료"
- [ ] 번아웃·사내 낙인이 있을 때 "뜻밖의 취미" / "아무도 원하지 않는 프로젝트"로도 극복할 수 있는가

### B3. S4~S6 추가 기능
- [ ] 한 달에 업무 사건(메신저) → 일상 사건(퇴근 후 카드) 순으로 2개가 나오고, 선택마다 결과 대화가 이어지는가
- [ ] 새로고침해도 이미 본 결과 대화가 다시 뜨지 않는가
- [ ] 캐릭터 선택 후 인생 목표 3장이 나오고, 메인 화면에 승진·목표 진행 막대가 보이는가
- [ ] 도구 "승진 심사 대상으로" → 월 시작: 1월 결산에 '인사발령'(성공) 또는 '보류'(누락)가 나오는가. 누락 2번이면 '후배가 먼저 달았다' 사건
- [ ] 50세 이상 과장급 이상에서 '희망퇴직 소문' → '희망퇴직 면담': 수락 선택지가 빨간 경고가 아니라 남색 안내로 보이고, 위로금이 연봉 24개월치인가
- [ ] 나이가 들수록 생활비와 사건 지출(청첩장 등)이 함께 오르는가 (물가 연 4%)
- [ ] 엔딩 화면에 인생 목표 달성/미달과 최고 직급이 나오는가

### C. 재미·밸런스 (자유 플레이, 도구 없이)
- [ ] 몇 살쯤 끝났는가, 원인은? (시뮬레이션상 구조조정 편중 — 체감도 그런가)
- [ ] 선택지 위험도 표시만으로 판단할 수 있는가
- [ ] 특성 획득(🌟) 순간이 눈에 띄는가
- [ ] 같은 사건이 너무 자주 나오는가

### D. 모바일
- [ ] 360px에서 글자·버튼이 잘리거나 겹치지 않는가
- [ ] 버튼이 손가락으로 누르기 충분히 큰가
- [ ] 다크 모드에서도 읽기 편한가

## 피드백 방법
화면 이름 + 무엇을 했는지 + 기대와 다른 점을 적어 주면 된다. 예: "결산 화면 — 체력 3에서 회식 이벤트, 결말 보기 버튼이 안 보임".
버그 재현이 필요하면 도구의 숨김 정보에 있는 `seed`를 함께 알려 주면 같은 판을 재현할 수 있다.
