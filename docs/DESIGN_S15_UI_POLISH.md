## 1. 단계

### S15-a 디자인 토큰 (모든 화면에 한 번에 적용)
- **글자**: `--fs-1..6` = 12/14/16/20/24/32px, 굵기 400/500/700. `.tiny`=12, `.small`=14, 본문 16, `h2`=24. 숫자는 `font-variant-numeric: tabular-nums`.
- **글꼴**: 본문·숫자 → 새 본문 글꼴(Q1). Black Han Sans는 로고 · 도장 · 엔딩 제목에만.
- **간격**: 4의 배수 (`--sp-1..8` = 4/8/12/16/20/24/32). **둥글기** `--r-sm 6 / --r-md 12 / --r-lg 16 / --r-full`.
- **색**: 회색 단계(잉크 900→100) + 브랜드 남색 + 강조 도장 빨강 + 상태(좋음/위험). 게이지 4색은 채도 낮춘 톤. **등급 색**은 Q2.
- **표면**: 테두리 1px 옅게, 그림자 `--elev-1`(카드) · `--elev-2`(시트)만. 상자 안 상자는 배경 톤 차이로.
- **버튼**: 48px · 본문 글꼴 700 · 그림자 없음 · 누를 때 0.98. 보조 버튼은 옅은 배경.
- **한글**: `word-break: keep-all`, 숫자·단위 정리.
- 인라인 스타일 → 유틸 클래스 (`.row`, `.stack-*`, `.muted` 등).

### S15-b 핵심 3화면
- 출근 화면: 사원증 가로형(카드 비율) 압축 · 세부는 탭하면 뒷면, 게이지 숫자 중심.
- 사건 메신저: 말풍선 그림자 제거, 연속 발화 묶기, 선택지 리스트 행.
- 평가표·결산: 표 선 서류, 숫자 오른쪽 정렬, 도장 한 번.

### S15-c 마감
- 움직임 규칙(등장 200ms · 사라짐 150ms, 도장은 평가·엔딩만), 다크 모드 재설계(브랜드 남색 유지), 아이콘 선 굵기 통일, 빈 상태.

## 2. 결정할 것
- **Q1 본문 글꼴** — 추천: **Pretendard** (한글 UI 표준에 가까운 깔끔한 글꼴, 숫자 폭 고정 지원, npm 패키지로 앱에 포함해 외부 요청 없음). 대안: Noto Sans KR 유지(설치 없음, 숫자 정렬 약함).
- **Q2 등급 색** — 추천: **남색 한 계열 진하기** (S 진한 남색+금 테두리 → D 옅은 회색). 대안: S·A만 색, B 이하 회색.

## 3. 검증
- 단계마다 헤드리스 Chrome 360×740 라이트·다크 스크린샷 (출근 · 사건 · 결산 · 평가표 · 엔딩 · 시작), 가로 넘침 0.
- 측정표(§0) 숫자를 단계 끝에 다시 잰다.

## 5. 구현 결과

### S15-a 디자인 토큰 (2026-11-19)
- 토큰: 글자 `--fs-xs..2xl`(12/14/16/20/24/32), 간격 `--sp-*`, 둥글기 `--r-sm/md/lg/full`, 그림자 `--elev-1/2`, 상태색 `--gold/success/info/warn`, 등급색 `--grade-*`.
- 기계적 변환(스크립트): 글자 크기 29종 → 6단계, 둥글기 15종 → 3단계(+원형·inherit), 직접 쓴 색 → 토큰, 게이지 4색 채도 낮춤(다크 모드 따로).
- 굵은 제목 글꼴 20곳 → 7곳(로고·도장·증명서·시작 화면·별명). 나머지는 본문 글꼴 700, 숫자 자리는 같은 폭 숫자.
- 주 버튼: 54px·제목 글꼴·아래 턱 그림자 → 48px·본문 700·단색, 누르면 0.98.
- 고정값 인라인 스타일 44곳 → 유틸 클래스(`.row` `.col` `.gap-*` `.fw-7` `.ink-2` …). 계산되는 값(조건부 색·너비)만 인라인으로 남김.
- 측정: 글자 크기 7종(기준 16px 포함) · 둥글기 8가지 표기(3단계 조합) · 제목 글꼴 7곳.
- 남은 것(S15-b로): 평가표 도장이 첫 등급 칩을 가림, 메신저 선택지 노란 인용 상자·내 말풍선 노랑, 사원증 세로 길이.

### S15-b 핵심 3화면 (2026-11-19)
- **사원증**: 가로형으로 압축(높이 약 절반). 위 = 남색 회사 띠 + 도장 빨강 선, 몸 = 작은 사진 · 이름·직급 · 팀·최근 평가 · 칩. **탭하면 뒷면**(입사·연봉·최근 평가·이직 + 바코드·사번). 사원증 전체가 버튼(`aria-pressed`).
- **메신저**: 말풍선 그림자 제거, **내 말풍선 남색**(노랑 → 브랜드색), '읽음' 회색, 같은 사람이 이어 말하면 이름·아바타 생략. 선택지는 리스트 행 + 오른쪽 `›`, 답장 미리보기는 노란 상자 → 왼쪽 선 인용, 결과 칩은 테두리 없는 옅은 배경.
- **평가표**: 도장을 제목 줄 오른쪽으로 옮겨 항목 등급 칩을 가리지 않게. 항목 사이 옅은 구분선, 숫자 같은 폭·오른쪽 정렬.

### S15-c 마감 (2026-11-19)
- **브랜드 표면 토큰** `--brand-bg/-hover/-fg/-fg-muted`: 주 버튼 · 사원증 띠 · 직급 칩 · 메신저 머리 · 아바타 · 내 말풍선. 다크 모드에서도 남색(#2f4270) + 흰 글자로 유지 (예전엔 하늘색 버튼 + 어두운 글자라 브랜드 인상이 사라졌다).
- **다크 모드**: 배경 #0f1420 · 카드 #171d2b · 대화 배경 #0b0f18(말풍선이 묻히지 않게), 게이지 색은 밝은 톤 따로.
- **움직임**: `--ease-out`, `--dur-in` 200ms · `--dur-out` 150ms. 대화 등장 0.7s → 0.3s, 카드 뒤집기 0.5s → 0.3s. 도장 찍는 연출(slam)은 평가표·엔딩에만 (승진 발령 도장은 정지).
- **아이콘** 선 굵기 2 → 1.75 (본문 글꼴과 무게 맞춤).
- **빈 상태** `.empty`(점선 상자 + 가운데 안내): 특성 없음 · 증감 기록 없음 · 도감 첫 방문.
- 확인: 헤드리스 Chrome 360×740 라이트·다크, 9개 화면(시작·사건·선택지·결산·평가표·평판 출처·출근·증감 시트·나) 가로 넘침 0. 테스트 231개 통과.
