### 0.2 원인 — 직무 단발 사건 20개 (직무당 4개)

**실험:** 직무 단발 사건 20개만 빼고 같은 1000판을 돌리면 실패율은 개발 14% · 인사 17% · 영업 25% · 재무 17% · 기획 18%가 된다. 기획 격차는 거의 사라지고 영업만 남는다.
→ **격차의 대부분은 직무 단발 사건의 숫자 설계에서 나온다.** 연재(S12)나 공통 사건 탓이 아니다.

| 직무 | 직무 사건 평판 합계 (판당) | 체력+정신 합계 | 봇이 주로 고르는 선택 | 진단 |
|---|---|---|---|---|
| 개발 | **+92** | −120 | 급한 불만 끄기(F−3 R+2), 작성자 찾기 | 확정 **평판 +** 선택지가 2개 있다 (`quick_patch`, `minimal`, `verify_slowly`) |

| 인사 | −73 | 0 | 대충 면접(✗ R−12), 연봉 인상 건의 | 안전한 선택지가 모두 평판 −5~−6 → 도박할 수밖에 없다 |

## 2. 설계 원칙 — 사건 하나의 "선택지 틀"

직무 단발 사건 20개를 같은 틀로 다시 잰다. 대사·상황은 그대로 두고 숫자만 바꾼다.

| 선택지 성격 | 규칙 | 예 |
|---|---|---|
| **버티기** (확정, 도박 없음) | 평판 −3 ~ +1. 공짜로 평판 +는 없다 | 재무 `cut_own` R+6 → **R+2 + 정신 −4** (팀원 원망) |
| **정공법** (자원을 내고 확률 높음) | 직무 자원 비용 8~12, 성공 60~70%, 성공 R+5~+8, 실패 R−4~−6 | 인사 `thorough` 그대로 |
| **승부수** (비용 없음, 확률 낮음) | 성공 40~55%, 성공 R+8~+12(+승진 포인트), **실패 평판 손실 상한 −8** | 기획 `realistic_alt` R−10 → **R−7**, 인사 `skim` ✗R−12 → **R−8** |

- 실패 손실 상한(−8)이 분산을 줄여 기획 OUSTED 연쇄를 막는다. 큰 손실(−10 이상)은 **고위험 표시가 있는 사건**에만 남긴다.
- 기댓값: 직무마다 4개 사건의 "봇이 고를 최선 선택"의 평판·자원 기댓값 합이 ±1.5점 안에 들도록 표로 맞춘다 (구현 때 표를 문서에 남긴다).
- 쿨다운: 영업 `cold_call` 4개월·`client_complaint` 5개월이 다른 직무보다 잦다 → **6개월**로 맞춘다. 직무당 쿨다운 합을 비슷하게.

## 4. 검증

1. `simulate` 리포트의 직무별 줄에 **'행동 안 씀' 봇 실패율**을 추가한다 (지금은 '행동 활용' 봇만 보여서 격차가 가려졌다).

3. 테스트: 직무별 실패율 차이 ≤ 20%p (시드 고정 300판, 느슨한 회귀 방지).
4. 난이도 3단계 요약이 목표대 안인지 다시 확인하고, 벗어나면 난이도 보정값만 조정.

### 6.2 균형에 미치는 영향
- 지금 난이도 목표(쉬움 3~8% · 보통 10~25% · 현실 40~55%)는 **늘 휴식하는 봇** 기준이다. 휴식의 +3/+3을 그냥 지우면 모든 난이도가 어려워진다.
- §1의 직무 목표 가운데 '행동 활용 신중 봇' 줄은 없어진다. 남는 기준: 신중 봇 직무별 실패 평균 ±10%p, 부장 도달 평균 ±10%p.

### 6.3 결정할 것
- **Q4 휴식 효과** → **자연 회복에 합친다**. `rules.monthly.naturalChange` 체력 +2→+5, 정신력 +3→+6. 회복 사건 ×1.3은 없앤다(작음, 시뮬레이션으로 확인)
- **Q5 별명 4종** → **사건 기반으로 살린다** (§6.4)

### 6.4 별명 4종 살리기 — '퇴근 후' 일상 사건 4개

지금 사건 가운데 자기계발·운동 선택지는 3개뿐이고 인맥·부업은 없다. 그래서 **월간 행동의 느낌을 가끔 뜨는 일상 카드로 옮긴다.**

| 새 일상 사건 (반복, 쿨다운 6개월) | 테마 선택지 | 별명 |
|---|---|---|
| 자격증 시험 접수 마감 | 접수하고 퇴근 후 공부한다 (집중력 +, 정신력 −, 돈 −) | 📚 주경야독 |
| 오랜만의 업계 모임 | 나가서 명함을 돌린다 (평판 +, 체력 −, 돈 −) | 🤝 마당발 |
| 지인의 부업 제안 | 해 본다 (현금 +, 정신력 −, 낮은 확률로 들켜 평판 −) | 💼 N잡러 |
| 회사 앞 헬스장 할인 | 등록하고 다닌다 (체력 +, 돈 −) | 🏋️ 철인 회사원 |

- 각 사건엔 "이번엔 넘긴다" 같은 무난한 선택지도 둔다. 효과는 S11 행동 한 달 치의 2~3배 정도로 작게 잡아 균형을 흔들지 않는다.
- 별명 조건: 새 규칙 `choiceCount`(이 선택들을 한 횟수 ≥ N). 기존 관련 선택지(주말 업무 공부, 자기계발 강의, 건강검진 뒤 운동 시작)도 셈에 넣는다. N은 시뮬레이션에서 각 별명 획득률 **10~25%**가 되게 정한다.
- `actionMonths` 규칙은 지운다. 별명 30종·도감 칸 수는 그대로.
