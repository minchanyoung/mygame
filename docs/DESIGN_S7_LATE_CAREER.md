# S7 설계안 — 이직(A2) + 50대 긴장감(B7)

> 상태: **승인 (2026-11-17)** — 네 질문 모두 추천안으로 결정 (Q1 초기화, Q2 직급 유지, Q3 '별을 달다' 엔딩, Q4 나이 듦 적용).
> 근거: 검토 브리핑 B7(50세 이후 긴장감 부족)·B8(이직 없음)·B6 잔여(정년 완주가 너무 쉬움), DEVELOPMENT_PLAN §5.4 승진과 이직.

## 0. 문제와 목표

| 문제 | 지금 | 목표 |
|---|---|---|
| 첫 직장에서 평생 | F등급에 들어가도 36년 그대로 | 중반에 한 번쯤 "옮길까?"를 고민하게 |
| 50세 이후 잃을 게 없음 | 실직 = 조기 은퇴(정상 엔딩) | 50대에도 지킬 것(목표·몸·돈)이 있고, 끝이 좋고 나쁨이 갈림 |
| 정년 완주가 쉬움 | 신중하게 하면 68% | 50대 위험 사건으로 35~50% |

자발적 퇴사는 여전히 없다(§26 Q3). 이직은 **회사를 옮기는 것**이지 실직이 아니다.

## 1. 이직 (A2)

### 1.1 흐름

1. **헤드헌터 연락** (업무 칸 사건, 메신저). 조건: 재직 2년 이상 · 평판 60 이상 · 28~54세 · PIP 경고 없음.
2. "이력서 보내본다" → 판정(평판·직급·최근 평가 보정). 성공하면 **이직 제안서** 1장이 생긴다.
   - 회사: 지금보다 **한두 등급 높은** 회사 (없으면 같은 등급의 다른 회사)
   - 연봉: 현 연봉 +15~30% (상대 회사 등급 범위 안)
   - 직급: 그대로 유지 (결정 필요 Q2)
3. 그달 **결산 화면에 '이직 제안서'** 카드: [옮긴다] / [남는다]. 다음 달로 넘어가면 사라진다.
4. 지금 회사가 눈치채는 선택지 **"카운터 오퍼를 받아낸다"**: 남는 대신 연봉 +5~10%, 대신 상사 신뢰 하락.

### 1.2 옮기면 생기는 일 (이득과 대가)

| 이득 | 대가 |
|---|---|
| 연봉 즉시 상승, 더 높은 등급 회사 | **승진 포인트·근속 초기화** (결정 필요 Q1) — 새 회사에선 처음부터 |
| 새 팀, 새 상사 — 나쁜 상사에게서 탈출 | 새 팀원과 관계를 다시 쌓아야 함 (기존 NPC는 기억 보존, 비활성) |
| 사내 낙인 같은 '회사 범위' 꼬리표가 사라짐 | **수습 3개월**: 텃세·적응 사건 가중, 평판 50으로 재시작 |
| 인생 목표(돈·부장) 경로가 바뀜 | 이직 직후 연말 평가는 업무 성과 표본이 적다 |

- 한 판에 이직은 **최대 2번**, 이직 후 2년 동안 헤드헌터 연락 없음.
- 첫 직장이 낮은 등급일수록 연락이 조금 더 자주 온다 (F·D 회사 탈출 경로).

### 1.3 새 사건 (메신저 대화)

헤드헌터 연락 · 경쟁사 리크루터 커피챗 · 수습 기간 텃세 · 전 직장 동료의 연락 · "왜 옮겼어요?" 회식 질문 — **5종**

## 2. 50대 긴장감 (B7)

### 2.1 나이 듦 (규칙)

- **50세부터 매달 체력 자연 회복 −1** (+2 → +1). 55세부터 한 번 더 (+0). (결정 필요 Q4)
- 50세 이후 연말 평가에 '근태·컨디션' 비중이 소폭 상승.

### 2.2 50대 위험 사건 (6종)

| 사건 | 조건 | 내용 |
|---|---|---|
| 건강검진 이상 소견 | 45세↑ (일상) | 재검·치료비(물가 연동) vs 무시 → 3개월 뒤 '재검 결과' 예약(체력 큰 손실) |
| 자녀 학원비·등록금 | 45세↑ (일상) | 큰 지출 — 돈 목표에 압박 |
| 부모님 간병 | 48세↑ (일상) | 돈 또는 정신력·근태 중 하나를 잃는 선택 |
| 나이 어린 상사 | 45세↑, 차장 이하 (업무) | 후배가 상사가 됨 — 정신력·자존심 |
| 디지털 전환 교육 | 48세↑ (업무) | 새 시스템 적응 실패 시 평판·집중력 손실 |
| **임원 후보 심사** | 부장, 50세↑, 평판 70↑ (업무) | 성공 → **'별을 달다' 엔딩** / 실패 → '희망퇴직 소문' 플래그 (결정 필요 Q3) |

### 2.3 끝의 좋고 나쁨이 갈린다

- 정년 은퇴 / 조기 은퇴는 그대로 정상 엔딩이지만, 엔딩 화면에 **은퇴 후 노후 등급**(순자산 기준: 여유·보통·빠듯)을 붙인다 → 50대에 돈을 지키는 이유.
- 인생 목표 '정년 완주'는 50대 위험 사건으로 자연스럽게 어려워진다 (목표 달성률 35~50%).

| 위치 | 변경 |

| 엔진 | `transfer.ts` — 제안 생성(시드 고정)·수락 처리(새 팀 생성, 기존 팀 배정 종료, 포인트·근속 초기화, 회사 범위 플래그 정리); 상태 머신 `MONTH_SUMMARY`에 `acceptTransfer`/`declineTransfer`; 나이별 자연 변화 |

## 3.5 구현 결과 (시뮬레이션 1,000회, 신중 봇 / 무작위 봇)

- 50세 전 실패 17.7% / 28.6%, 정년 은퇴 72% / 14%, 별을 달다(임원) 5.4% / 16.6%
- 이직 경험 81% / 74% — 봇은 제안을 쉽게 받는다. 사람은 승진 포인트 초기화를 보고 더 망설일 것으로 본다
- 노후 등급 (여유/그럭저럭/빠듯): 5 / 55 / 40% · 31 / 65 / 4%
- 정년 완주 목표 74% / 11% (두 봇 평균 약 43%)
- 구현 중 추가 수정: 빚 원금 상환 상한도 물가 연동(고정이면 후반에 이자를 못 따라가 빚이 저절로 불어남), 시뮬레이션 봇이 이직·임원·카운터 오퍼의 가치를 계산하도록

## 4. 결정 기록

- **Q1. 이직하면 승진 포인트·근속은?** 추천: 초기화. 연봉을 얻는 대신 승진 레이스를 다시 시작하는 맞교환이 생긴다.
- **Q2. 이직 시 직급은?** 추천: 유지. (높은 등급 회사로 가면 한 단계 낮추는 방안도 가능)
- **Q3. 임원 승진 성공은?** 추천: '별을 달다' 특별 정상 엔딩으로 즉시 마무리. 임원 직급을 계속 플레이하려면 사장·이사회 계층이 필요해 범위가 커진다.
- **Q4. 나이 듦(50세↑ 체력 회복 감소)을 넣을까?** 추천: 넣는다. 50대 긴장감의 바탕.
